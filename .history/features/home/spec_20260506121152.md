# Feature: Home Page

## Goal

Implement index.html as the main landing page of my portfolio.

## Designs

Home page layout with a dark theme, centered hero section, and clean sections for about and projects.

## Inspiration

Inspired by kentcdodds.com for the clean layout and simple structure, but adapted to a darker theme with a more modern look.

## Work

A navbar at the top with links on the right (About, Projects)
A hero section with my name and a short tagline "Developer · Designer · Creator" and a button that scrolls to projects
A full screen background image in the hero section
An about section with a circular profile image, short intro, and a list of details about me
A tools section listing languages and technologies I use
A projects section with cards showing project title, description, and tech used
Each project has a button linking to the project or code
A footer with GitHub, LinkedIn, and email links
Hover behavior: buttons invert colors, links underline on hover, cards highlight with border change

## Deliverables

index.html loads properly in the browser
Navbar stays at the top when scrolling
Hero section fills the screen with background image and text
About section shows image and information clearly
At least 2 project cards are displayed
Project links open correctly
Footer shows all social links
Hover effects work on links and buttons
Responsive layout works on mobile and desktop
