# Feature: Project Details Page

## Goal

Implement project.html to show details of a single project.

## Designs

Same dark theme and clean layout as the home page for consistency.

## Inspiration

Same style as home page with simple structure and clear sections.

## Work

A back button at the top that returns to the home page
A main title using h1 for the project name
A section describing the project and its purpose
A tech stack section listing tools and languages used
A section showing at least one image or screenshot
A "View Code" button linking to GitHub
Hover behavior: buttons change color on hover

## Deliverables

project.html opens correctly
Back button navigates to home page
Project title and description are visible
Tech stack is clearly listed
At least one image is displayed
GitHub link opens in a new tab
Layout matches the style of index.html
Responsive on mobile and desktop
