Trash Sorting AI

A machine learning model that classifies garbage in real time and triggers physical LED responses.

About

Trained on Teachable Machine to sort waste into 4 categories: glass, plastic, paper, and metal. A p5.js web app reads the predictions and sends them to a Raspberry Pi Pico via serial, lighting up different LEDs based on the result.

Tech Stack

  • Teachable Machine
  • p5.js
  • Arduino
  • Raspberry Pi Pico

What I Learned

Connecting a machine learning model to physical hardware taught me how software and electronics can work together. Handling serial communication between the browser and the microcontroller was the trickiest part.
